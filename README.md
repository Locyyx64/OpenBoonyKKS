# OpenBoonyKKS
A basic E-Commerce Website, made to establish a more comfortable marketing place, for everyone.

## Basic description
The main goal of this project, is to aid retailers, looking for a place to sell their products, or just to lend a helping hand
to any newcomers, intending to monetize either digital or physical assets.

The Web Application essentially uses XAMPP as the webserver.[^1]
It was mainly written in ***PHP***, ***JavaScript***, ***CSS*** and ***Sass***, ***MySQL** (with phpmyadmin)*,
and I'm also intending to develop some ***Bash** (Bourne Again Shell)* utilities, and the ability to run it as a *Docker container*,
with the provided *Dockerfile*.

## Installation / Integration
- First of all, you have to have XAMPP installed.
- Next, execute the ***init.sh*** script.
- After that, you will be able to access the webapp on localhost, or on the *www.boonykks.com* domain, if you agreed to it.

>Note: This project is still in it's lowest **Alpha stage**, so it will receive a lot of new features, and bugfixes.

[^1]: Unfortunately, I haven't figured out how to automatize this yet.
